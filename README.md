# UNP_PROJECT_REGRESSION_STOCK_MARKET_

This project, titled "Predicting Next-Day Stock Opening Prices: A Comparative Regression Analysis Across Global Markets," uses
machine learning to predict next-day stock opening prices from past market data. It compares NIFTY50, FTSE100, S&P500,
HANGSEN, Brent crude, gold, Bitcoin, bond yields, and currency rates. After data cleaning and analysis, Linear Regression with
a 75:25 split performed best, with a MAPE of 0.49%. The results show that historical market indicators can effectively support
stock price prediction and provide useful insights for understanding global market trends.
